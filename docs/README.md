# ByteQuay

> A calmer home for GitHub pull requests.

ByteQuay is a native macOS app for reviewing the pull requests you authored or
were asked to review. It combines a focused Home page with native PR details,
diffs, checks, activity, comments, approvals, merge controls, and an embedded
GitHub view.

The app is being rebuilt around this small foundation. Agent development and
task orchestration are not part of the current product.
