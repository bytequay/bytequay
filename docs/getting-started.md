# Getting started

Install the latest `.dmg` from the
[Releases page](https://github.com/bytequay/bytequay/releases), then drag
**ByteQuay.app** to **Applications**.

Current builds require macOS 14+ and JDK 25. Follow the instructions for your
release.

On first launch, choose **Use my GitHub CLI login**, or enter a personal access
token and choose **Connect with token →**. If needed, run `gh auth login` in
Terminal before retrying the CLI option. Manage the connection later in
**Settings → Integrations → GitHub**.

Home shows your watched repositories, contribution history, and recent
activity. Open **Pull requests** to see authored PRs and review requests, then
select one to load its description, checks, files, and activity. Use
**Home → Repos you watch → + Watch** to add a repository workspace.

Continue with the [user guide](documentation/README.md) for ByteQuay's goals,
agent setup, Goals, Memory, and the other feature guides.
