CARD ANATOMY
Row 1 — workspace name + topology chip: gray direct or amber ⑂ upstream/name; red needs attention replaces it when anything failed.
Row 2 — mono context: default branch, and for a fork the followed upstream.
Row 3 — two independent status chips, always in the same order: code, then labels & people (metadata).
Row 4 — PR/task counts when ready, otherwise a one-line plain-language status.
Footer — activity dot + last event; a Retry button appears only on retryable failures. Each card is an article whose whole surface opens the workspace via its primary link; Retry is a sibling button, never nested inside another control.
