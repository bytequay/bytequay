# Release notes

Every ByteQuay release is documented here, newest first, one page per
version.

## Conventions

Each release page groups changes under:

- **Highlights** — the headline changes.
- **New features** — additions.
- **Improvements** — refinements to existing behavior.
- **Bug fixes** — corrections.
- **Breaking changes** — anything that requires user action.

## Versions

- [0.1.0](./0.1.0.md) — initial release

:::tip Adding a release
Copy `0.1.0.md`, rename it to the new version, fill in the sections, and add
the page id to the `Releases` category in `sidebarsReleases.ts`.
:::
