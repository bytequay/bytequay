# Pull requests

The pull-request screen has a filterable list on the left and the selected PR
on the right.

- **Open** shows active account-relevant PRs and PRs from currently monitored repositories.
- **Mine** shows every pull request you authored, including merged and closed work.
- **Review** shows pull requests awaiting your review.
- **Viewed** shows review work you completed.
- **Closed** shows merged and closed pull requests.

The detail pane provides the description, changed-file patches, check results,
and recent GitHub activity. From the same pane you can comment, react to the
description or comments, approve, merge, refresh the cached detail, or open the
PR in the embedded GitHub view.

Comments, reactions, approvals, and merges are direct user actions; ByteQuay
does not publish or merge automatically.
